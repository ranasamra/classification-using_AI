This project focuses on using Artificial Intelligence and Machine Learning for classification. The model learns patterns from the given dataset and predicts the category of new data.

▶️ How to Run

Clone the repository:

git clone https://github.com/ranasamra/AI-Classification.git
cd AI-Classification


Install the required libraries:

pip install -r requirements.txt


Run the project:

python main.py

📊 Results

The model is evaluated using classification metrics such as accuracy, precision, recall, and F1-score.
